# Гильдия — лавка навыков

Мобильная веб-лавка для D&D: игроки выбирают персонажа, покупают навыки за очки и просматривают коллекцию. Мастер может добавлять игроков и навыки и менять баланс.

## Запуск

Требуется Node.js 18 или новее.

```sh
npm start
```

Откройте `http://localhost:3000` на компьютере или адрес сервера в браузере телефона. Данные хранятся в `data/store.json` на сервере; файл создаётся при первом запуске. Для постоянного хранения разместите приложение на сервере с постоянным диском и делайте резервные копии этого файла.

Код мастера по умолчанию: `1234`. Для смены задайте переменную окружения `ADMIN_PIN` перед запуском, например `ADMIN_PIN=ваш-код npm start`.

**Важно:** это простой прототип для доверенной группы, а не защищённый многопользовательский сервис. Выбор игрока свободный, а код мастера передаётся серверу напрямую; для публичного размещения нужны HTTPS, полноценная авторизация игроков, защита доступа и безопасное хранение данных.
